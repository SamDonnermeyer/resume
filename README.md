# Sam Donnermeyer · personal site

Live at **https://samdonnermeyer.github.io/resume/**

A single static page. No framework, no build step for the page itself, no tracking. One HTML file, one stylesheet, one script, and SVG charts drawn in the browser from a small data file.

## What's on it

- **A ridgeline of Colorado's 2025–26 winter.** Thirty SNOTEL snow stations, north to south, with a dot strip showing each station's peak as a share of its normal peak.
- **This winter's snowpack against normal.** A simple average of 99 stations compared with their NRCS medians.
- **A career timeline.**

Every chart has a text description, keyboard access and a table view of its data.

## How it was built

I built this site with [Claude Code](https://claude.com/claude-code), an AI coding agent. I set the direction and the constraints: the positioning, the snowpack story, and what could and could not be shown publicly. The agent wrote the code and ran the checks, and I approve what gets published. Commits carry a `Co-Authored-By` line for that reason.

That way of working is the subject of the "Agent operating layer" project on the site: agents do the work, and a review step sits in front of anything that lands.

Checks run before each publish:

- Text contrast of at least 4.5:1 and chart marks of at least 3:1, in light and dark themes
- No sideways scrolling from 375px to 1440px wide
- Keyboard access to every chart, and reduced-motion settings respected
- Every number on the page traced back to the data file

## Data

`assets/js/data.js` is generated by `scripts/build_data.py` from the public [USDA NRCS AWDB REST API](https://wcc.sc.egov.usda.gov/awdbRestApi/). The script uses only the Python standard library.

```bash
python3 scripts/build_data.py
```

It pulls daily snow water equivalent and the NRCS median for every active Colorado SNOTEL station for water year 2026, keeps the stations with a complete year of both, and writes:

- thirty stations, evenly spaced from north to south, for the ridgeline
- a statewide daily average and median for the comparison chart

Two caveats, both stated on the site:

- SNOTEL data is provisional and can be revised. The published file was pulled on November 12, 2026, so a fresh pull may differ slightly.
- The statewide series is a simple, unweighted average of stations. Official statewide figures weight stations by basin and came in slightly lower for April 1.

## Run it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

| `assets/js/site.js` | Charts and interactions, no dependencies |
