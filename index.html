Personal project · Automation

Hunt Command

A daily intelligence page for Colorado big-game seasons.

Before a hunt, the useful information is spread across a dozen sites. A scheduled Python job pulls weather forecasts, snowpack, wildfire activity, closures and local news for each hunt unit, then renders one self-contained HTML page and deploys it to an access-controlled site. It runs unattended every morning.

  • Python
  • Scheduled jobs
  • Static HTML
  • Git-based deploys
  • Cloudflare Pages

Colorado's snowpack peaked 29 days early, at 55% of normal

One of the public feeds Hunt Command reads: snow water equivalent, winter 2025–26.

This winter Normal (median)

Simple average of 99 SNOTEL stations against their NRCS medians; provisional data pulled Nov 12, 2026. By April 1 that average was 26% of normal. Official statewide figures weight stations differently and came in slightly lower, about 22–24% (Colorado Climate Center).

Personal project · AI enablement

Agent operating layer

Scheduled AI coding agents that handle routine work and report back.

A personal setup for running AI coding agents on a schedule. Headless runs produce a daily briefing on an access-gated page. Guardrails are built in: hooks keep credentials out of agent transcripts, and delegated code changes happen in isolated git worktrees and pass a review gate before they land.

  • Claude Code
  • MCP
  • Hooks
  • Git worktrees
  • Cloudflare Access
