Personal project · Automation

Hunt Command

A daily intelligence page for Colorado big-game seasons.

Before a hunt, the useful information is spread across a dozen sites. A scheduled Python job pulls weather forecasts, snowpack, wildfire activity, closures and local news for each hunt unit, then renders one self-contained HTML page and deploys it to an access-controlled site. It runs unattended every morning.
